# Partner logos — drop files here

Upload one logo per partner, named exactly as below (SVG preferred; PNG at
2x display size also fine). Once the files are here, set
`LOGOS_UPLOADED = true` in `components/home/CredStrip.tsx` to switch the
strip from text names to logos.

| Partner                          | Expected filename                        |
| -------------------------------- | ---------------------------------------- |
| World Vision International Nepal | `world-vision-international-nepal.svg`   |
| University of Pittsburgh         | `university-of-pittsburgh.svg`           |
| Kathmandu University             | `kathmandu-university.svg`               |
| Nepal Bank Limited               | `nepal-bank-limited.svg`                 |

If you upload PNGs instead, keep the same base names (`.png`) and update
the `logo` paths in `CredStrip.tsx` to match.
